# Svelte frontend

This is a plain Svelte application built with Vite. It produces a static
`build/index.html` for the V desktop shell.

## Developing

Install dependencies with `npm install`, then start the development server:

```sh
npm run dev

```

## Building

To create a production version of the app:

```sh
npm run build
```

You can preview the production build with `npm run preview`.
